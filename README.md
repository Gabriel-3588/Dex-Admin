# Dex Admin (Open-Source)

È um projeto público open-source que é um `Admin System(Sistema de Admin)` que esta disponivel somente para Roblox Studio que ajuda os jogadores a administrarem bem o jogo em geral, contendo varias funcionalidades incriveis é super faceis de usar para facilitar o uso do roblox ou funções em geral.

## Installation

1. Baixe o Dex Admin `.rbxm` vá na pagina de [Releases](https://github.com/Gabriel-3588/FastFps/releases) baixe la.
2. Coloque o arquivo `.rbxm` no roblox studio é leia o READ_ME dentro dele para ajudar a configuração é o uso.
3. Apenas compativel com o roblox studio, NÃO RECOMENDO QUE MEXA NA API APENAS EM CASOS NECESSARIOS!

## Features

 - CommandBar bruto, é muito facil de usar com autocomplete muito funcional é com uma Interface muito bonita.
 - Compativel com o TopbarPlus, ou seja não vai bugar quando você for usar o CommandBar.
 - Sistema de notificações, avisos de rank, ou erros na hora de executar um comando. É com fallback.
